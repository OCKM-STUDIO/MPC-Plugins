# OCKM Wave

A lean wavetable synth for Akai MPC standalone hardware, by OCKM. It is also a short course in
wavetable synthesis: each of the first 16 presets shows one idea, and this README explains that
idea in plain English and tells you which knob to turn to hear it. Presets 17–48 are ready-to-use
sounds for house and techno.

## Requirements

- MPC OS 3.10.1 or later.
- Preferences → Enhancements (Beta) → turn on **Enable Enhancements** and **External Plugin Support**.
- Install: copy the `OCKM - VST - OCKM Wave` folder into `VST2 Plugins` at the root of an SD card or
  USB stick, insert it and restart the MPC. Load it on a plugin program (External Plugins → OCKM Wave).

## What a wavetable is

A normal synth oscillator plays one fixed shape, such as a saw or a square, over and over. A
**wavetable** is a stack of different shapes, called **frames**, like the pages of a flip-book.
Each frame is a single cycle of a wave. OCKM Wave's tables each have 16 frames.

**WT Pos** picks the page you hear. Between two pages the synth blends them, so turning
WT Pos slowly morphs one shape into the next. Let an envelope, the LFO or the mod wheel turn
WT Pos for you and the tone moves while the note plays. That moving tone is what wavetable
synths are for.

The 8 tables (all generated by maths inside the plugin; no sample files):

| Table | Frame 1 → frame 16 | What it shows |
|---|---|---|
| Shapes | sine → triangle → saw → square | morphing between the classic shapes |
| Harmonics | 1 harmonic → 16 harmonics, added one at a time | WT Pos works as a brightness control |
| Pulse | square → thin pulse | pulse-width modulation, done with a table |
| Vowels | "ah" → "eh" → "ee" → "oh" → "oo" | formants: shaping the sound like a mouth |
| Sync | a saw with a restarted partner climbing 1× → 8× | the tearing hard-sync sweep, stored as frames |
| FM | a sine modulated harder and harder | metallic FM tones, stored as frames |
| Fold | a sine folded back on itself harder and harder | distortion, stored as frames |
| Steps | smooth saw → 4-step staircase | lo-fi, digital shapes |

## The lessons (presets 01–16)

Load a preset, play a note or a chord, then turn the knob named in **Try**.

| # | Preset | The idea in plain English | Try |
|---|---|---|---|
| 01 | Init Saw | One frame is one cycle of a wave. Here WT Pos sits on the saw frame of **Shapes** and nothing moves, so it sounds like an ordinary saw synth. | Turn **WT Pos** slowly from 0 to 100% and hear sine → triangle → saw → square. |
| 02 | Shape Morph | **WT Pos morph.** The LFO sweeps WT Pos back and forth through the Shapes table, so the tone changes shape on its own. | **LFO1 Rate** for speed, **LFO1>WT Pos** for how far it travels. |
| 03 | Wheel Scan | **WT Pos by hand.** The mod wheel is wired to WT Pos on the **Harmonics** table: push it up and harmonics join one by one. | The **mod wheel**. Set **Wheel>WT Pos** negative to make it work backwards. |
| 04 | Pluck by Table | **A position envelope.** The mod envelope (Env 2) pushes WT Pos up at the start of each note and lets it fall back, so each note starts bright and turns dull, with no filter at all. | **Env2 Decay** for the length of the "pluck"; **Env2>WT Pos** for how bright the start is. |
| 05 | Pluck by Filter | **Compare with 04.** The same pluck the classic way: a saw through a low-pass filter that the envelope opens and closes. A filter removes harmonics smoothly from the top; the table in 04 removes them one at a time from a fixed set. | Flip between presets 04 and 05 on the same notes. |
| 06 | Table PWM | **Pulse width as a table.** The LFO moves WT Pos through the **Pulse** table, widening and narrowing the pulse: the hollow, chorused sound of pulse-width modulation. | **LFO1>WT Pos** for depth, **LFO1 Rate** for speed. |
| 07 | Talking Pad | **Formants.** The **Vowels** table holds mouth shapes; the LFO, locked to the MPC's tempo (1/2 note), makes the pad "say" vowels in time with the beat. | **LFO1 Div** for a different rhythm; **WT Pos** to choose which vowels. |
| 08 | Sync Sweep | **Hard sync, stored as frames.** A slow mod-envelope attack climbs through the **Sync** table: the tearing, rising sync-lead sound. | **Env2 Attack** for the sweep time. |
| 09 | FM Bell | **FM, stored as frames.** The first frame is a sine; later ones are frequency-modulated harder and harder. The envelope starts high and falls, like a bell: bright strike, mellow tail. | **Env2>WT Pos** for the strike; **Env1 Decay** for the ring. |
| 10 | Fold Growl | **Folding.** A wavefolder bends the wave back on itself, adding buzzy harmonics. An LFO locked to 1/8 notes moves WT Pos through the **Fold** table: a growling mono bass. | **LFO1>WT Pos**, **Cutoff**. |
| 11 | Step Grit | **Quantised frames.** The **Steps** table turns a smooth saw into a staircase: fewer steps, more digital grit. | **WT Pos**: higher means fewer, bigger steps. |
| 12 | Warp Sync | **Warp: Sync.** Warp changes *how* a frame is read rather than which frame. Sync reads the frame up to 4× faster and restarts every cycle. Here it turns a plain **sine** into a sync sweep, driven by the envelope. | **Env2>Warp**, or set **Warp Amt** by hand. |
| 13 | Warp Bend | **Warp: Bend.** Squeezes the first half of the cycle and stretches the second, a "phase distortion" tone that gets more nasal as it bends. The LFO moves it. | **Warp Amt**, **LFO1>Warp**. |
| 14 | Warp Mirror | **Warp: Mirror.** Plays each frame forwards and then backwards inside one cycle, which gives a hollow, organ-like sound an octave brighter. | **Warp Amt** blends from normal (0%) to fully mirrored (100%). |
| 15 | Unison Stack | **Unison.** Five copies of the oscillator, each slightly detuned and spread left to right, make one big, wide, moving sound. | **Unison** (1–5), **Detune**, **Width**. Width 0 makes it mono again. |
| 16 | Aliasing Free | **Mipmaps.** Play this bright **Sync** frame high up the keyboard. Very bright waves at high pitches can produce "aliasing": harsh, out-of-tune whistles. OCKM Wave stores each frame at 10 brightness levels and plays a duller copy the higher you go, so it stays clean. | Play the top octaves; compare with **Warp Quantize** (see "Honest notes"). |

## Names you may know from other wavetable synths

The on-screen names follow the usual wavetable-synth wording. The big difference is how you
connect modulation: on a computer synth you drag an envelope or LFO onto a knob and set the ring
around it. The MPC can't drag and drop, so each connection is its own knob, named
**source>target**. **Env2>Cutoff** is "Env 2 dragged onto Cutoff", and its value is the size of
the ring.

| You may know it as | In OCKM Wave |
|---|---|
| Osc A wavetable menu, WT POS | **Wavetable**, **WT Pos** |
| Warp menu and amount | **Warp**, **Warp Amt** |
| Unison voices, detune, width | **Unison**, **Detune**, **Width** |
| Sub oscillator | **Sub** (a sine one octave down) |
| Octave | **Oct** |
| Mono / legato, portamento | **Voicing** (Poly / Mono / Legato), **Porta** |
| Filter type, cutoff, res, key track | **Filter Type** (LP / BP / HP), **Cutoff**, **Res**, **Key Trk** |
| Env 1 (always the volume) | **Env1 Attack / Decay / Sustain / Release** |
| Env 2 dragged onto a knob | **Env2 A/D/S/R** plus **Env2>WT Pos**, **Env2>Warp**, **Env2>Cutoff** |
| LFO 1, its BPM switch and rate | **LFO1 Shape**, **LFO1 BPM** (On = locked to the MPC tempo), **LFO1 Rate** / **LFO1 Div** |
| LFO 1 dragged onto a knob | **LFO1>WT Pos**, **LFO1>Warp**, **LFO1>Cutoff**, **LFO1>Pitch** |
| Mod wheel dragged onto WT POS | **Wheel>WT Pos** |
| Velocity to volume | **Velo>Amp** |
| Master volume | **Master** |

Not here: a second oscillator, noise, more envelopes and LFOs, a mod matrix, macros, effects
(use the MPC's own), an arpeggiator. The filter and Env 2 are per note (each note of a chord
gets its own sweep); the LFO is shared, so a chord moves together.

**OSC**

|---|---|---|---|

| Warp Amt | Sub (sine one octave down) | Velo>Amp (velocity → loudness) | |

**FLT+ENV**

| Filter | Env 1 (amp) | Env 2 | Env 2 to |
|---|---|---|---|
| Filter Type (LP / BP / HP) | Env1 Attack | Env2 Attack | Env2>WT Pos |
| Cutoff | Env1 Decay | Env2 Decay | Env2>Warp |
| Res | Env1 Sustain | Env2 Sustain | Env2>Cutoff |
| Key Trk (cutoff follows the keys) | Env1 Release | Env2 Release | *badge* |

**LFO**

| LFO 1 | LFO 1 to | Wheel to |
|---|---|---|
| LFO1 Shape | LFO1>WT Pos | Wheel>WT Pos |
| LFO1 BPM (Off: Hz; On: locked to the MPC tempo) | LFO1>Warp | |
| LFO1 Rate (when BPM is Off) | LFO1>Cutoff | *badge* |
| LFO1 Div (when BPM is On) | LFO1>Pitch (vibrato) | |

The LFO is shared by all notes, so a chord moves together. When locked to the tempo it follows
the MPC's song position while playing. Pitch bend is ±2 semitones; the sustain pedal works in Poly.

## Voices and CPU

6 voices in Poly; Mono and Legato use one. Measured with the test harness on a desktop core and
multiplied by 20 as a rough MPC One estimate (not yet measured on the hardware):

| Case | Desktop | MPC One estimate |
|---|---|---|
| 4-note chord, "18 Deep Chord" (2 copies) | 0.22% | about 4.5% |
| 4-note chord, "22 Wide Pad" (5 copies) | 0.31% | about 6% |
| Worst case: 6 voices × 5 copies, Mirror warp, all modulation | 0.70% | about 14% |

Unison is the expensive part: every extra copy costs nearly as much as another note. If the MPC
stutters, lower **Unison** first. Plucks with Env1 Sustain at 0% free their voice as soon as they
fade out, so fast patterns cost very little.

The wavetables (2.6 MB) are built once when the plugin first loads and shared by every instance.
That takes about 40 ms on a desktop, so expect a short pause (well under a second) on the MPC One.

## Honest notes

- **Plain tables are alias-free; warps add a little grit.** With Warp Off, a saw at C7 keeps
  everything that isn't a true harmonic 78 dB down. The warps choose a duller copy of the frame to
  compensate, but the sharp corners they create (the restart in Sync, the kink in Bend and Mirror,
  the steps in Quantize) are not fully smoothed: at 50% warp, unwanted tones sit 36–51 dB down at
  C5 and 25–39 dB down at C7. Usually masked in a mix and part of the character, especially for
  Quantize, which is meant to be gritty.
- **Brightness levels switch in steps** as the pitch rises. With very long glides over several
  octaves you may hear the top end change slightly.
- **No on-screen help text or waveform display.** The MPC's plugin screen can't show live
  waveforms, and the UI format has no help pop-ups, so this README is the help.
- **Changing Voicing** lets sounding notes ring out and starts fresh, so don't switch it mid-phrase.

## Not in v1

A second wavetable oscillator, noise, cross-modulation between oscillators; loading your own
wavetables from `Content/`; more LFOs or envelopes, a mod matrix, macros; effects (use the MPC's
own insert effects); a second filter, filter drive, 24 dB or ladder filters; more than 6 voices,
MPE, poly aftertouch, an arpeggiator; a waveform display.

## Build and test

Run these from the MPC-Plugins repo root. `SDK` is the MPC Plugin SDK folder:

```
SDK=${MPC_SDK:-/Users/simon/Projects/mpc-plugin-builder-sdk}
```

```
python3 $SDK/tools/build.py "OCKM Wave"
$SDK/.sdk-tools/host_sim "OCKM Wave"/build/native/*.dylib test --wav "OCKM Wave/build/test.wav"
clang++ -std=c++17 -O2 -I$SDK/framework "-IOCKM Wave/src" "OCKM Wave/tests/harness.cpp" -o "OCKM Wave/build/harness" && "OCKM Wave/build/harness" "OCKM Wave/build/demo.wav"
python3 $SDK/tools/package.py "OCKM Wave"
```

The harness checks every promise in SPEC.md section 9 (peaks, aliasing, morphing, clicks, warp,
unison, voices, legato and glide, all-notes-off, CPU), ends with `ALL PASS`, and renders
`build/demo.wav`: all 48 presets in order, about 4.8 seconds each.

To redraw the skin after changing `ui.json`: build with `--target native`, run
`python3 "OCKM Wave/make_skin.py"` (champagne tint is the default), then build again.
